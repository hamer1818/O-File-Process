# O File Processor

PyQt6 ile oluşturulmuş, bir dizindeki dosyaları kolayca yönetmenizi sağlayan çok dilli bir dosya yönetim uygulaması.

[English](../README.md) | [Azərbaycanca](README_az.md) | [Español](README_es.md) | [Русский](README_ru.md) | [中文](README_zh.md)

## Özellikler

- İsme göre dosya filtreleme
- Birden fazla dosyayı aynı anda yeniden adlandırma
- Dosyaları kopyalama ve yeniden adlandırma
- Belirli metni içeren dosyaları silme
- Çoklu dil desteği (İngilizce, Türkçe, Azerice, İspanyolca, Rusça, Çince)

## Kurulum

1. Bu depoyu klonlayın:

```bash
git clone https://github.com/hamer1818/file-processor.git
```

2. Gerekli bağımlılıkları yükleyin:

```bash
pip install -r requirements.txt
```

3. Uygulamayı çalıştırın:

```bash
python main.py
```

## Kullanım

1. Uygulamayı çalıştırın:

```bash
python main.py
```

2. Seçilen bir dizin seçin
3. Kullanılabilir özellikler:
   - Dosyaları filtrele: Filtre kutusuna metin girin ve "Apply Filter" butonuna tıklayın
   - Dosyaları yeniden adlandır: "eski yeni" girin ve "Rename Files" butonuna tıklayın
   - Dosyaları kopyalama ve yeniden adlandırma: "eski yeni" girin ve "Copy and Rename Files" butonuna tıklayın
   - Dosyaları silme: Dosyaları eşleşen metin girin ve "Delete Files" butonuna tıklayın
