# O File Processor

**O File Processor** — современное настольное приложение на базе **PyQt6** для профессионального управления файлами. Построено на чистой архитектуре **MVC**, предлагает пакетное переименование, копирование и безопасное удаление с интуитивным 3-панельным интерфейсом.

[![GitHub](https://img.shields.io/badge/GitHub-hamer1818%2FO--File--Process-blue?logo=github)](https://github.com/hamer1818/O-File-Process)

---

## 🚀 Основные функции

### 📁 Умная навигация по папкам
- **Боковая панель быстрого доступа:** Рабочий стол, Документы, Загрузки, Музыка, Изображения, Видео
- **Выбор произвольной папки:** Выберите любую директорию

### 🔍 Живой поиск и предпросмотр
- **Мгновенная фильтрация:** Ищите файлы при вводе
- **Предпросмотр действий:** Видите количество затрагиваемых файлов

### 📝 Пакетное переименование
- **Найти и заменить:** Замена текста в именах файлов

### 📋 Копировать и переименовать
- **Сохранить оригиналы:** Создание копий с новыми именами

### 🗑️ Безопасное удаление
- **Поиск по шаблону:** Удаление файлов с определённым текстом
- **Диалог подтверждения:** Список файлов перед удалением

## 🛠️ Установка

```bash
git clone https://github.com/hamer1818/O-File-Process.git
cd O-File-Process
python -m venv venv
.\venv\Scripts\activate  # Windows
pip install -r requirements.txt
python main.py
```
