# Файловый Процессор

Многоязычное приложение для управления файлами, созданное с помощью PyQt6, позволяющее легко управлять файлами в директории.

[English](../README.md) | [Türkçe](README_tr.md) | [Azərbaycanca](README_az.md) | [Español](README_es.md) | [中文](README_zh.md)

## Возможности

- Фильтрация файлов по имени
- Массовое переименование файлов
- Копирование и переименование файлов
- Удаление файлов, содержащих определенный текст
- Поддержка нескольких языков (английский, турецкий, азербайджанский, испанский, русский, китайский)

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/hamer1818/file-processor.git
```

2. Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
python main.py
```

## Использование

1. Запустите приложение:

```bash
python main.py
```

2. Выберите директорию
3. Доступные функции:
   - Фильтрация файлов: Введите текст в поле фильтра и нажмите кнопку "Apply Filter"
   - Переименование файлов: Введите "старое новое" и нажмите кнопку "Rename Files"
   - Копирование и переименование файлов: Введите "старое новое" и нажмите кнопку "Copy and Rename Files"
   - Удаление файлов: Введите совпадающий текст и нажмите кнопку "Delete Files"
