# Procesador de Archivos

Una aplicación multilingüe de gestión de archivos creada con PyQt6 que permite administrar fácilmente archivos en un directorio.

[English](../README.md) | [Türkçe](README_tr.md) | [Azərbaycanca](README_az.md) | [Русский](README_ru.md) | [中文](README_zh.md)

## Características

- Filtrado de archivos por nombre
- Renombrado masivo de archivos
- Copiar y renombrar archivos
- Eliminar archivos que contienen texto específico
- Soporte multilingüe (Inglés, Turco, Azerbaiyano, Español, Ruso, Chino)

## Instalación

1. Clona este repositorio:

```bash
git clone https://github.com/hamer1818/file-processor.git
```

2. Instala las dependencias necesarias:

```bash
pip install -r requirements.txt
```

3. Ejecuta la aplicación:

```bash
python main.py
```

## Uso

1. Inicia la aplicación:

```bash
python main.py
```

2. Selecciona un directorio
3. Funciones disponibles:
   - Filtrar archivos: Ingresa texto en el cuadro de filtro y haz clic en "Apply Filter"
   - Renombrar archivos: Ingresa "viejo nuevo" y haz clic en "Rename Files"
   - Copiar y renombrar archivos: Ingresa "viejo nuevo" y haz clic en "Copy and Rename Files"
   - Eliminar archivos: Ingresa el texto coincidente y haz clic en "Delete Files"
