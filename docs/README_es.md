# O File Processor

**O File Processor** es una aplicación de escritorio moderna basada en **PyQt6** para la gestión profesional de archivos. Construida con una arquitectura **MVC** limpia, ofrece renombrado por lotes, copiado y eliminación segura con una interfaz intuitiva de 3 paneles.

[![GitHub](https://img.shields.io/badge/GitHub-hamer1818%2FO--File--Process-blue?logo=github)](https://github.com/hamer1818/O-File-Process)

---

## 🚀 Características Principales

### 📁 Navegación Inteligente de Carpetas
- **Barra Lateral de Acceso Rápido:** Acceso con un clic a Escritorio, Documentos, Descargas, Música, Imágenes y Videos
- **Selección de Carpeta Personalizada:** Navegue y seleccione cualquier directorio

### 🔍 Búsqueda en Vivo y Vista Previa
- **Filtrado Instantáneo:** Busque archivos mientras escribe
- **Vista Previa de Acción en Vivo:** Vea exactamente cuántos archivos se verán afectados

### 📝 Renombrado por Lotes
- **Buscar y Reemplazar:** Reemplace texto específico en múltiples nombres de archivo

### 📋 Copiar y Renombrar
- **Preservar Originales:** Cree copias con nombres modificados

### 🗑️ Eliminación Segura
- **Coincidencia de Patrones:** Elimine archivos que contengan texto específico
- **Diálogo de Confirmación:** Lista todos los archivos antes de eliminar

## 🛠️ Instalación

```bash

cd O-File-Process
python -m venv venv
.\venv\Scripts\activate  # Windows
pip install -r requirements.txt
python main.py
```
