# O File Processor

A multi-language file management application built with PyQt6 that allows you to easily manage files in a directory.

[Türkçe](docs/README_tr.md) | [Azərbaycanca](docs/README_az.md) | [Español](docs/README_es.md) | [Русский](docs/README_ru.md) | [中文](docs/README_zh.md)

## Features

- Filter files by name
- Rename multiple files at once
- Copy and rename files
- Delete files containing specific text
- Multi-language support (English, Turkish, Azerbaijani, Spanish, Russian, Chinese)

## Installation

1. Clone this repository:

```bash
git clone https://github.com/hamer1818/file-processor.git
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python main.py
```

## Usage

1. Run the application:

```bash
python main.py
```

2. Select a folder using the "Select Folder" button
3. Use the available features:
   - Filter files: Enter text in the filter box and click "Apply Filter"
   - Rename files: Enter "old new" in the rename box and click "Rename Files"
   - Copy and rename: Enter "old new" and click "Copy and Rename Files"
   - Delete files: Enter text to match files and click "Delete Files"
